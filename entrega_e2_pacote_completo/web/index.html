CIÊNCIA COM RESPONSABILIDADE

Integração comprovável.
Limites explícitos.

Este painel registra e consulta os dados direto na API de Prognóstico de Readmissão (Fase 3): a classificação da Árvore de Decisão, a explicação do Gemini e o parecer da revisão humana ficam no mesmo banco (tia_fase2), disponíveis para consulta e auditoria nesta tela.

O objetivo preditivo do projeto requer treinamento e validação próprios. Uma resposta de linguagem não substitui uma Árvore de Decisão validada.

Acesso local e sem chaves no navegador. O formulário envia avaliações à API da porta 5000. Acessibilidade orientada pelas WCAG 2.2; conformidade integral depende de auditoria.
