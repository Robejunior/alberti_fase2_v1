================================================================================
                         ❌ PROBLEMAS COMUNS & SOLUÇÕES
================================================================================

"API Offline" na Sidebar
  └─ API não está rodando
     Solução: Abrir outro terminal e rodar: python src/app.py

"Connection refused" ao avaliar
  └─ Porta 5000 já em uso ou API não respondendo
     Solução: netstat -ano | findstr :5000 ; taskkill /PID <PID> /F

Streamlit não abre
  └─ Porta 8501 já em uso
     Solução: streamlit run frontend.py --server.port 8502

"ModuleNotFoundError: No module named 'streamlit'"
  └─ Dependências não instaladas
     Solução: pip install -r requirements.txt

Para mais problemas: Consulte COMECE_AQUI_FASE3.md
